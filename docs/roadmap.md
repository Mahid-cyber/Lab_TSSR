# Feuille de route du Lab_TSSR

Le portfolio sera enrichi progressivement à partir des projets réellement réalisés.

## ✅ Déjà documenté

### MDT / WDS / PXE — Windows 11 26H2
Déploiement automatisé par PXE UEFI, diagnostic de l'erreur MDT 5616/15299, application du correctif Microsoft et validation sur Hyper-V et serveur physique.

### VMware ESXi — virtualisation et migration
Installation d'ESXi sur serveur Dell, création de machines virtuelles et participation à une migration Windows Server 2012 → 2016.

## 🔄 À documenter

### Active Directory / DNS / DHCP
Documenter l'architecture de domaine, les rôles des serveurs et les scénarios de configuration réalisés dans le laboratoire.

### Proxmox / virtualisation
Documenter l'installation, la configuration réseau et les scénarios de virtualisation.

### Linux / Docker
Documenter l'administration Linux et les services déployés avec Docker / Docker Compose.

### GLPI / ITSM
Documenter l'installation, la configuration et les tests de la plateforme ITSM.

## 📸 Preuves

Les captures d'écran seront ajoutées uniquement lorsqu'elles apportent une preuve utile : configuration, diagnostic, commande, erreur ou résultat.

## 🔐 Publication

Avant chaque ajout :

- supprimer les secrets ;
- anonymiser les données sensibles ;
- ne pas publier de mots de passe, clés ou tokens ;
- vérifier les adresses et informations d'infrastructure ;
- conserver les captures nécessaires à la compréhension du projet.
