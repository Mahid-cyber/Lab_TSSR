# Kit LinkedIn — Projet phare 2026

## Positionnement

Le projet peut être présenté comme un **projet phare 2026** du portfolio personnel. Éviter toute formulation laissant entendre qu'il s'agit d'un prix ou d'une distinction reçue.

### Titre du projet LinkedIn

**Déploiement automatisé de Windows 11 26H2 avec MDT / WDS / PXE**

### Description courte

Mise en place d'une chaîne de déploiement Windows 11 26H2 basée sur Windows Server 2022, Active Directory, DNS, DHCP, WDS, MDT, WinPE et PXE UEFI. Le projet a été validé sur Hyper-V puis sur serveur physique.

### Compétences à sélectionner

LinkedIn permet d'ajouter jusqu'à 5 compétences à un projet. Les 5 plus représentatives pour ce projet sont :

1. Microsoft Windows Server
2. Active Directory
3. Microsoft Deployment Toolkit (MDT)
4. Windows Deployment Services (WDS)
5. PXE / UEFI

Le projet a été particulièrement intéressant pour sa partie dépannage.

Le déploiement rencontrait l'erreur **5616 / 15299 — Verify BCDBootEx**. J'ai procédé par étapes pour isoler le problème : vérification du démarrage UEFI, de la structure GPT, des pilotes WinPE, des lettres de volumes et de BCDBoot.

Après application du correctif Microsoft concernant `Microsoft.BDD.Utility.dll` puis régénération complète du Deployment Share, le déploiement a été validé avec **0 erreur et 0 avertissement** sur les deux environnements.

## Mise en avant sur le profil

Selon les fonctionnalités disponibles sur le compte, ajouter le projet dans **Projets** et/ou placer le contenu dans la section **Sélection / En vedette**.

LinkedIn permet d'ajouter un projet depuis le profil et d'y associer une description, jusqu'à 5 compétences, des médias/liens et des dates. La page d'aide LinkedIn indique aussi qu'un projet peut être partagé sous forme de post après son enregistrement.

## Ordre recommandé

1. Publier le site portfolio.
2. Ajouter le projet dans LinkedIn > Profil > Ajouter une section > Ajouter un projet.
3. Ajouter l'URL du portfolio comme média/site du projet.
4. Sélectionner les 5 compétences.
5. Ajouter une ou deux captures fortes dans le post.
6. Publier le post avec un lien vers le portfolio.
7. Vérifier que le post est visible par **Tout le monde / Anyone**, selon tes préférences de confidentialité.
8. Mettre à jour la section Coordonnées du profil avec le portfolio.

## Captures recommandées pour LinkedIn

Pour le post, privilégier une petite sélection :

- résultat final **Success / 0 erreur / 0 avertissement** ;
- erreur initiale 5616 / 15299 ;
- architecture/configuration MDT ou WDS ;
- démonstration UEFI/GPT si lisible.

Les détails plus techniques restent dans le dépôt.

## Hygiène de publication

Avant publication, vérifier chaque capture :

- aucun mot de passe ;
- aucun token ou clé ;
- aucune adresse IP publique ;
- aucune donnée interne d'entreprise ;
- aucune information d'identification inutile.

Le portfolio doit rester centré sur la démarche technique et les résultats réellement obtenus.
